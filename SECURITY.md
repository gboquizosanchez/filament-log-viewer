# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 2.x     | ✅        |
| 1.x     | ❌        |

## Reporting a Vulnerability

Please report security vulnerabilities via [GitHub Security Advisories](https://github.com/gboquizosanchez/filament-log-viewer/security/advisories/new) rather than a public issue.

You should receive a response within 5 business days.
